# Запрос ПО

## Стандартное ПО

Стандартный набор программного обеспечения (браузер, офисный пакет, мессенджер, VPN-клиент, антивирус, IDE для разработчиков) устанавливается автоматически при подготовке рабочего места (см. `it-new-employee-setup.md`) и не требует отдельного запроса.

## Как запросить дополнительное ПО

1. Перейдите в раздел «Запрос оборудования и ПО» на HR/IT-портале.
2. Выберите категорию «Программное обеспечение», укажите:
   - название и версию продукта;
   - деловое обоснование (для какой задачи нужно);
   - предпочтительный срок использования (постоянно / временно, с датой окончания).
3. Заявка автоматически направляется на согласование руководителю, затем — в IT-отдел на техническую проверку совместимости и лицензирования.
4. Для платного ПО дополнительно требуется согласование бюджета от финансового отдела — срок рассмотрения увеличивается до 3–5 рабочих дней.

## Сроки установки

- Бесплатное или уже лицензированное компанией ПО из каталога — устанавливается удалённо IT-отделом в течение 1 рабочего дня после согласования.
- Новое платное ПО, требующее закупки лицензии — от 3 до 10 рабочих дней в зависимости от поставщика.
- ПО с открытым исходным кодом, не входящее в каталог — проходит дополнительную проверку службой информационной безопасности перед установкой (до 5 рабочих дней).

## Каталог одобренного ПО

Список ПО, доступного для самостоятельной установки без согласования, опубликован в разделе «Каталог ПО» портала. Сотрудники с правами локального администратора могут устанавливать программы из каталога самостоятельно без создания заявки.

## Ограничения

- Установка ПО, не входящего в каталог и не прошедшего проверку безопасности, запрещена политикой компании и может быть автоматически заблокирована системой контроля (MDM/EDR).
- Пиратское и нелицензионное ПО устанавливать запрещено категорически — нарушение фиксируется и передаётся в службу безопасности.
- Для ПО с доступом к клиентским данным или продакшн-системам требуется дополнительное согласование от службы информационной безопасности вне зависимости от стоимости.

## Часто задаваемые вопросы

**Сколько по времени рассматривается запрос на бесплатное ПО из каталога?**
Если ПО уже в каталоге одобренных программ — установка происходит в течение 1 рабочего дня без дополнительных согласований.

**Можно ли установить ПО самостоятельно, если есть права администратора на ноутбуке?**
Только если ПО есть в каталоге одобренного ПО — установка любого другого ПО без заявки нарушает политику безопасности, даже при наличии прав администратора.

**Что делать, если нужное ПО не найдено в каталоге?**
Оформите заявку через раздел «Запрос оборудования и ПО» с деловым обоснованием — IT-отдел проверит возможность добавления в каталог или разовой установки.
