# Подключение к VPN

## Кому нужен VPN-доступ

VPN обязателен для подключения к внутренним корпоративным ресурсам (внутренние базы данных, административные панели, dev/stage-окружения) при работе вне офисной сети — из дома, из другого города, из-за рубежа.

## Запрос доступа

1. Создайте заявку в разделе «Доступы» HR/IT-портала: тип доступа — «VPN», укажите причину (удалённая работа, командировка).
2. Заявка автоматически согласуется руководителем.
3. После согласования IT-отдел выдаёт доступ в течение 1 рабочего дня, приходит уведомление на почту с инструкцией по настройке.

## Настройка клиента

Компания использует протокол **WireGuard** через корпоративный клиент `CorpVPN`.

1. Скачайте клиент из раздела «Инструменты» портала (доступны версии для macOS, Windows, Linux).
2. Импортируйте конфигурационный файл, присланный на почту после одобрения заявки (файл действителен 48 часов, после — нужно запросить новый через тикет).
3. Войдите под корпоративной учётной записью и пройдите двухфакторную аутентификацию (push-уведомление в приложении Corp Authenticator).
4. Нажмите «Подключиться» — статус подключения отображается в трее.

## Проблемы с подключением

- **Не проходит аутентификация** — проверьте, что пароль актуален (см. `it-password-reset.md`) и приложение Corp Authenticator обновлено до последней версии.
- **VPN подключается, но нет доступа к внутренним ресурсам** — проверьте, не истёк ли срок действия конфигурационного файла (48 часов с момента выдачи).
- **Медленное соединение** — попробуйте переключиться на ближайший VPN-шлюз вручную в настройках клиента (раздел «Server region»).
- **Клиент не запускается после обновления ОС** — переустановите клиент из последней версии в разделе «Инструменты».

## Ограничения и безопасность

- VPN-сессия автоматически завершается после 10 часов бездействия.
- Запрещено передавать конфигурационный файл другим сотрудникам — доступ персонализирован и логируется.
- Доступ автоматически отзывается при увольнении или переводе в отдел, для которого VPN не требуется.

## Часто задаваемые вопросы

**Нужен ли VPN для работы из офиса?**
Нет, внутри офисной сети доступ к ресурсам предоставляется напрямую без VPN.

**Как продлить доступ, если он был выдан временно на период командировки?**
Подайте новую заявку в разделе «Доступы» — автоматическое продление не предусмотрено.

**Что делать, если конфигурационный файл утерян или скомпрометирован?**
Немедленно сообщите в IT-поддержку через тикет с пометкой «Срочно: компрометация доступа» — старый конфиг будет отозван и выдан новый.
